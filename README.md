# Финансовый календарь

Настольное приложение для macOS — календарь денежного потока вперёд с ручным вводом.
Отвечает на вопросы «хватит ли денег до даты X?» и «когда я достигну цели Y?»,
позволяет проигрывать сценарии. Всё хранится локально, без сети и облака.

Требования — в `TZ.md` (v1.1), контекст решений — в `interview-brief.md`.

## Стек

Tauri 2 (Rust) + React + TypeScript (strict). Расчётное ядро — отдельный крейт
[`crates/core`](crates/core) без зависимостей от UI и Tauri; тестируется `cargo test` без запуска UI.

## Разработка

Нужны: macOS 13+, Node 22+, Rust (stable, через [rustup](https://rustup.rs)).

```bash
npm install
npm run tauri dev      # запуск приложения
npm run lint           # ESLint
npm run typecheck      # tsc
npm test               # тесты TS (vitest)
cargo test --workspace # тесты Rust, включая расчётное ядро
npm run check:r10      # проверка R10: нет файлов данных в дереве
```

Опционально — pre-commit хук с проверкой R10:

```bash
printf '#!/bin/sh\nnode scripts/check-r10.mjs\n' > .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

## Сборка .dmg

```bash
npx tauri build --bundles dmg
```

Релиз: тег `v*` (например `v0.1.0`) запускает GitHub Actions, который собирает universal `.dmg`
и публикует его в GitHub Releases. Сборка не подписывается и не нотаризуется.

## Первое открытие неподписанного приложения

macOS (Gatekeeper) блокирует неподписанные приложения. Один раз откройте так:

- перетащите приложение в «Программы», затем в Finder нажмите на нём правой кнопкой (или Control + клик) →
  **Открыть** → **Открыть**; или
- «Системные настройки → Конфиденциальность и безопасность» → после первой попытки запуска
  нажмите **Всё равно открыть**.

## Данные и репозиторий

Данные приложения лежат вне репозитория: `~/Library/Application Support/<идентификатор приложения>/`.
Репозиторий публичный, поэтому файлы БД, бэкапы и `.dmg` исключены в `.gitignore`, а CI
(`scripts/check-r10.mjs`) падает, если в дереве есть файл БД (по расширению или сигнатуре `SQLite format 3`)
или файл из каталога `Backups/`. В тестовых данных — только синтетика.
